# 1. 凸性
凸性（Convexity） 是描述一个集合、函数或空间“没有凹陷、没有空洞、任意两点连线不出去”的性质。
## 1.1 凸集

**定义** 设 $C \subseteq \mathbb{R}^n$ 是一个集合。  
如果对任意 $ x, y \in C $ 和任意 $ \lambda \in [0,1] $，都有：

$$
\lambda x + (1-\lambda)y \in C
$$

则称 $C $ 为凸集。

其中：
- $x, y$ 是集合中的任意两点；
- $ \lambda x + (1-\lambda)y $ 表示连接 $ x $ 和 $ y $ 的线段上的点;
> 比如一维的时候,设 $$x=2$，$$y=6$,
> 那么$\lambda x + (1-\lambda)y  = 6 -4\lambda$表示2和6之内的点也就是区间$[2,6]$
> 
> 二维的时候,设：$x = (x_1, x_2), \quad y = (y_1, y_2)$
> 公式写成：
$$
P(\lambda) = \lambda x + (1-\lambda)y
$$
> 展开：
$$
P(\lambda) = (\lambda x_1 + (1-\lambda)y_1,\ \lambda x_2 + (1-\lambda)y_2)
$$
即：
$$
\begin{cases}
 P_1 = y_1 + \lambda(x_1 - y_1)\\
 P_2 = y_2 + \lambda(x_2 - y_2)
\end{cases}
$$
> 这正是二维平面中**直线的参数方程**。
- $\lambda = 0$ 时得到 $y$，$\lambda = 1$ 时得到 $x$，$0<\lambda<1$时得到中间点。

- 例子

> 一维的情况 
> 1. $C = [2,6]$ => 凸集
> 2. $C = [1,2] \cup [5,6]$ => 非凸集, $x = 2,y=5,\lambda = 0.5$时得到$P = {3.5} \notin C$ 
> 3. $C = {3}$ => 凸集
> 4. $C = {\varnothing}$ => 空集是最简单的凸集
> 
> 二维的情况
> 1. $C = \{(x,y) | x^2 + y ^2 \le 1\}$ => 凸集,圆内任意两点的线段都在圆中
> 2. $C = \{(x,y) | 1 \le x^2 + y ^2 \le 4 \}$ => 非凸集,$A = (0,2),B=(0,-2),\lambda=0.5$得到$P = (0,0) \notin C$

## 1.2 凸函数

设函数 $ f: \mathbb{R}^n \to \mathbb{R} $，其定义域$\operatorname{dom} f$为凸集。

如果对任意 $x, y \in \operatorname{dom} f $ 和任意 $ \lambda \in [0,1] $，都有：
$$
\boxed{f(\lambda x + (1-\lambda)y) \le \lambda f(x) + (1-\lambda)f(y)}
$$
则称 $f$ 是**凸函数**。

如果不等号反向：$f$ 是**凹函数**。
